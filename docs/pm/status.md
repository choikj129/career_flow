- 마지막 갱신: 2026-11-25
- 지금 단계: **M2와 간단한 지원 흐름 완료. B-14(분석 강화·맞춤 이력서 추천도)와 이력서 세션 요청(맞춤 이력서는 이력서 세션에서, D-33) 병합(11-25). 다음은 실사용(공고 분석 → 지원 서류 카드 → 필요하면 요청 복사 → 지원 완료)과 M1.5 실사용 점검**
- 열린 결정: 없음 — [../decisions.md](../decisions.md)
- 진행 중인 에이전트 작업: 없음
- 저장소: `main`이 `origin/main`보다 커밋 37개 앞섬(push 안 함) (GitHub `choikj129/career_flow`, **공개**)

## 2. 다음에 할 일 (PM 기준 우선순위)

1. **실사용**: 공고 분석([다시 분석]) → 지원 서류 카드에서 추천 프로필 PDF 받기(맞춤 이력서 추천도가 높으면 [이력서 세션 요청 복사] → 이력서 세션에서 맞춤 PDF) → 사이트 지원 → [지원 완료]. 문제가 나오면 먼저 고친다.
2. **M1.5 실사용 점검**: 아래 4장의 수동 확인. 그동안 PM은 B-1(S-1 확인, haiku 1회)을 처리할 수 있다.
3. **M3 4단계 면접 준비**: 사용자가 시작을 지시하면 `/feature-workflow`로.
