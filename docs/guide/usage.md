# Career Flow 사용 안내

내 PC에서만 쓰는 취업 활동 관리 도구입니다. 주소는 `http://127.0.0.1:3939`이고 이 PC 밖에서는 열리지 않습니다.

## 설치 (한 번만)

1. Node.js 22를 설치합니다.
2. 프로젝트 폴더에서 패키지를 설치합니다.
   ```
   npm i
   npx playwright install chromium
   ```
3. Claude Code CLI를 설치하고 터미널에서 `claude`를 실행해 로그인합니다. 모든 AI 작업은 이 로그인(구독)으로 처리하며 API 키는 쓰지 않습니다.

## 실행

`scripts/start-career-flow.cmd`를 더블클릭합니다. 처음에는 빌드를 하고, 서버가 켜지면 브라우저가 열립니다. 창을 닫으면 서버도 꺼집니다.

직접 실행하려면 다음과 같습니다.

```
npm run build
npm run start
```

## 처음 쓰는 순서

1. 설정에서 **로그인 확인**을 눌러 Claude Code 로그인을 확인합니다(사용량이 아주 조금 듭니다).
2. **기본 이력서**에서 기존 이력서 파일을 올리거나 텍스트를 붙여넣어 가져옵니다. 내용을 확인하고 저장하면 v1이 됩니다.
3. **가져오기**에서 이미 지원한 내역을 각 사이트의 지원 현황 화면에서 복사해 넣고, 검토한 뒤 등록합니다.
4. 설정의 **사이트 로그인**에서 로그인이 필요한 사이트에 한 번 로그인해 둡니다. 열린 창에서 직접 로그인하고 창을 닫습니다. 앱은 비밀번호를 저장하지 않습니다.
5. **공고 등록**에 링크를 넣으면 분석이 시작됩니다.

## 데이터와 백업

- 모든 데이터는 프로젝트 폴더의 `data/` 안에 있습니다(DB, 업로드한 파일, 브라우저 로그인 정보, 백업). 이 폴더는 git에 올라가지 않습니다.
- 앱을 켜면 하루에 한 번 자동 백업을 만듭니다(`data/backups/`, 최근 30개 보관). 최근 백업 시각은 설정에서 볼 수 있습니다.
- AI 작업이 끝나면 작업용 복사본(`data/ai-work/<번호>/`)은 바로 지웁니다. 올린 이력서·캡처 원본(`data/uploads/`)은 남겨 두며, 설정의 "올린 파일 정리"에서 지울 수 있습니다(이미 저장한 이력서와 지원 기록은 그대로입니다).
- 다른 PC로 옮기거나 되돌릴 때는 앱을 끈 뒤 `data/career-flow.db`를 백업 파일로 바꿉니다.
- 데이터 폴더를 바꾸려면 환경변수 `CAREER_FLOW_DATA_DIR`에 폴더 경로를 지정합니다.

## 문제가 생기면

| 증상 | 확인 |
|---|---|
| 분석이 "로그인이 필요합니다"로 실패 | 터미널에서 `claude`를 실행해 다시 로그인한 뒤 [다시 시도] |
| "Claude Code CLI를 찾을 수 없습니다" | `claude --version`이 터미널에서 되는지 확인. 다른 경로에 설치했다면 `CLAUDE_BIN`에 실행 파일 경로 지정 |
| 앱을 끈 사이 중단된 분석 | "중단됨"으로 표시됩니다. [다시 시도]를 누르세요 |
| 공고 본문을 읽지 못함 | 로그인이 필요한 사이트면 설정에서 로그인하고, 안 되면 본문을 복사해 붙여넣으세요 |
