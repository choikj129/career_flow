# 기본 서류로 냈을 때 "지원 폴더 안 씀" 알림 (D-34)

- 요청 (2026-11-27): "맞춤 이력서 생성을 했지만 웹에서 기본 서류로 제출했다면 지원\{공고} 는 삭제하도록 기능 추가" → "그냥 웹에서 이 디렉터리 안 쓰니까 삭제하라는 알럿 정도만 띄워줘"
- 결정: D-34 — 앱은 지우지 않고 알림만. 지우는 일은 사용자가 이력서 세션에 시킨다(D-31 그대로).
- 브랜치: `fix/folder-notice` (폴더 `C:\project\career_flow-folder-notice`)
- 상태: 개발 중

## 1. 설계 (PM)

- 앱은 이력서 세션이 맞춤본을 실제로 만들었는지 알 수 없다. 가장 가까운 신호는 그 공고에서 **[이력서 세션 요청 복사]를 누른 것**이다.
- 복사 표시 저장: 복사가 성공하면 브라우저 저장소(localStorage)에 `cf:session-request-copied:{postingId}` = 복사 시각을 남긴다. DB·서버 변경 없음. 저장소를 못 쓰면(예외) 조용히 넘어간다(그때는 알림이 안 뜰 뿐).
- 알림 조건: [지원 완료] 또는 [기록 수정]을 저장했을 때, 그 공고에 복사 표시가 있고 저장한 이력서가 "이력서 세션 맞춤본"이 **아니면**(기본 서류·이력서 파일·모름 등).
- 알림 모양: 저장 뒤 화면(공고 상세)에 닫을 수 있는 안내 상자(notice warn) 한 번:
  - "이 공고는 이력서 세션 맞춤본이 아닌 서류로 냈습니다. 이력서 세션에서 만든 이 공고의 지원 폴더(지원\{회사 이름})는 쓰지 않으니, 이력서 세션에 지워 달라고 하세요."
  - [닫기]. 닫거나 한 번 보이면 그 공고의 복사 표시를 지워 다시 뜨지 않게 한다.
- 이력서 세션 맞춤본으로 저장하면 알림 없음(복사 표시는 그대로 둬도 됨 — 나중에 기본 서류로 고치면 그때 알림).
- 기존 토스트("지원 완료로 저장했습니다")는 그대로.
- 문서: `docs/spec/screens.md` 지원 완료·기록 수정 저장 뒤 안내, `docs/spec/product.md` 한 줄(D-34), `docs/test/test-cases.md` 새 TC-FN-01~.
