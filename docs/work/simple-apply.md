# 간단한 지원 흐름 (프로필 PDF 기본, 맞춤은 필요할 때만)

- 요청 (2026-11-23): "맞춤 이력서 탭에서 내려받기를 위로 올림. 추가 조정, 바뀐 곳, 제출 전 체크리스트, 프로필 바꾸기 > 추가조정은 뭘 하는 건지 모르겠음. 일단 기본적으로 이력서 폴더에 만들어진 파일들을 기본으로 하고 조정이 필요한 경우에만 AI 호출해서 수정하도록. (필요한 경우에만 해당 내용들이 보여야 함.)" + "앱이 같은 내용으로 만들되 파일이 계속 복제되지 않았으면 함. … 수정이 필요한 경우 공고 맞춤 pdf로 만들기 (이 땐 복제해도 됨.)"
- 브랜치: `feat/simple-apply`
- 상태: 완료 (2026-11-24 main 병합)
- 관련 결정: D-25(PDF는 저장하지 않고 그때그때 만든다), D-31 c(앱은 D 드라이브를 건드리지 않는다)

## 1. 설계

사용 흐름: 공고 분석 → 추천 프로필 확인 → **그 프로필 PDF를 받아** 사이트에 지원 → [지원 완료]에 그 프로필 기록. 공고에 맞춰 고칠 때만 맞춤본(리비전)을 만든다.

### 1-1. 맞춤 이력서 탭: 맨 위 "지원 서류" 카드 (항상)

- 한 줄: **B4 오너십** 80% (추천) · 백엔드 · 키트 14. 프로필 선택 상자(8개, 직무별 묶음). 처음 값 = 분석의 추천 1순위, 추천이 없으면 직무 기본 프로필(B1/F1).
- 버튼: **[이력서 PDF] [경력기술서 PDF]**, 작은 [미리보기].
- 내용 = 키트의 기본 서류를 그 프로필 순서로 조립한 것(추가 조정 없음). 이력서 프로젝트 `프로필` 폴더의 파일과 같은 내용이다.
- **저장하지 않는다**. 받을 때마다 만든다(리비전·파일이 생기지 않음, D-25와 같은 방식). D 드라이브는 읽지 않는다(D-31).
- 파일 이름: `{이름}_{이력서|경력기술서}_{회사}.pdf` (회사가 없으면 직무).
- 키트가 없거나 오류가 있으면 지금처럼 안내만.

### 1-2. 아래 "공고에 맞춰 고치기" (필요할 때만)

- 접힌 상자. 맞춤본이 하나도 없으면 접혀 있고, 있으면 펼쳐져 있다.
- 안에는 지금의 맞춤 기능을 그대로 둔다: 추가 조정 고르기·맞춤본 만들기, 공고 용어 맞추기(AI), 다듬기(AI), 바뀐 곳, 제출 전 체크리스트, 작업 공간 요청, 리비전 고르기.
- 맞춤본이 있으면 그 맞춤본의 **내려받기를 이 상자 맨 위**로 올린다(지금은 맨 아래).
- 상자 제목 옆 한 줄 안내: "공고 용어를 바꾸거나 성과 순서를 조정할 때만 씁니다. 맞춤본은 공고마다 따로 저장됩니다."

### 1-3. [지원 완료]의 제출 서류(이력서)

- 선택지에 키트의 **모든 프로필**을 둔다: "기본 서류 백엔드 · B4 오너십" … (지금은 직무 기본 프로필만).
- 미리 골라 두는 값: 이 공고의 최신 맞춤본 → 없으면 **분석 추천 1순위 프로필** → 없으면 직무 기본 프로필 → 지원일에 맞는 이력서 파일 → 모름 (지금 순서에서 "기본 서류" 단계만 프로필 단위로 바뀜).
- 저장 형식: 이미 있는 "기본 서류" 기록에 프로필 id·이름이 들어 있다(새 표·열 없음). 선택지 값에 프로필 id를 더한다. 예전 기록(프로필 없음)은 그대로 읽는다.
- 통계 "프로필별"은 이 프로필로 센다(지금 코드 그대로).

### 만들지 않는 것

- D 드라이브 프로필 PDF 읽기, 지원 폴더 만들기(이력서 세션 몫).
- 포트폴리오 PDF 내려받기.
- 맞춤 기능 삭제(접어 둘 뿐).
- 선택한 프로필을 공고별로 저장하기(지원 완료 때 기록되는 것으로 충분).

### 바뀌는 문서

- 화면 문서 `docs/spec/screens.md`: 공고 상세의 맞춤 이력서 탭, 지원 완료 창의 제출 서류.
- 기획서 7.5(맞춤 이력서) 한 줄: 기본은 프로필 PDF, 맞춤은 필요할 때만.
- 테스트 케이스 `docs/test/test-cases.md`.

### 테스트 케이스 (초안, 번호는 개발 때 이어서)

- 프로필 PDF 경로: 프로필 순서로 조립한 md로 PDF·md를 만들고 DB에 리비전을 만들지 않는다. 없는 프로필·키트는 404, 다른 사이트 요청은 막지 않아도 됨(GET, 저장 없음). 파일 이름에 회사.
- 지원 서류 카드: 추천 1순위가 처음 값, 추천이 없으면 기본 프로필, 선택을 바꾸면 내려받기 주소가 바뀜.
- 고치기 상자: 맞춤본이 없으면 접힘, 있으면 펼침, 내려받기가 상자 맨 위.
- 제출 서류: 프로필 8개 선택지, 기본값 순서, 저장 후 라벨 "기본 서류 백엔드 · B4", 통계 프로필별에 B4로 셈, 예전 기록 읽기.
- E2E: 1024·1440 폭에서 카드 한 줄이 깨지지 않음(한글 낱말 끊김 없음).
