# 영어 회사 이름에 한글 별칭 자동 붙이기

- 요청 (2026-11-27): "sionic AI 이런 애들을 사이오닉으로 검색해도 나오게 할 수 없나" → PM이 수동 별칭 추가(Sionic AI에 "사이오닉 AI" 넣음)와 자동 방법을 안내 → 사용자: "만들기"
- 브랜치: `feat/company-alias` (폴더 `C:\project\career_flow-company-alias`)
- 상태: 개발 중
- 관련 결정: D-04(회사 연결·별칭), B-14(분석 결과 형식)

## 1. 설계 (PM, 작은 기능)

- 공고 분석 결과의 공고 정보(`result.posting`)에 선택 칸 `companyAliases: string[]`(최대 3개)을 더한다.
  - 프롬프트 규칙: 회사 표시 이름에 한글이 없으면(영문·숫자만) 그 이름의 한국어 읽기(예: "Sionic AI" → "사이오닉 AI", "사이오닉에이아이")를 넣는다. 공고 본문에 한글 회사명·법인명이 있으면 그것을 먼저 넣는다. 한글 이름이면 반대로 본문에 있는 영문 이름만 넣는다(없으면 빈 배열). 지어낸 이름은 넣지 않는다(본문 근거 또는 발음 그대로의 읽기만).
  - CLI 출력 스키마에서는 필수(빈 배열 허용), 저장 스키마에서는 optional(옛 결과 그대로 읽힘). 새 DB 열·표 없음.
- 저장: `saveAnalysis`에서 공고의 회사(이미 연결됐거나 새로 만든 회사)에 `addCompanyAlias`로 각 별칭을 추가한다.
  - 이미 같은 키(정규화 후)가 그 회사에 있으면 건너뛴다. **다른 회사의 키와 같으면 넣지 않는다**(회사가 잘못 합쳐지는 것 방지; 기존 addCompanyAlias 동작을 확인하고, 충돌 시 조용히 건너뛰게).
  - 별칭은 앞뒤 공백 제거, 1~50자, 회사 표시 이름과 같은 키면 건너뛴다.
  - 별칭 추가 실패는 분석 저장을 실패시키지 않는다.
- 회사 연결이 사용자가 직접 넣은 회사명(posting-edit)이어도 별칭은 그 회사에 붙는다.
- `claude` 호출 수는 그대로(분석 1회).
- 문서: `docs/spec/product.md` 분석 출력·회사 별칭 한 줄, `docs/test/test-cases.md` 새 TC-CA-01~.
