## 1. 설계 (PM)

### 1) 지원 폴더 안내 문구

- 새 문구: "이 공고는 기본 서류로 냈습니다. 이력서 세션에서 만든 지원 폴더(지원\{회사 이름})는 쓰지 않으니 지워 주세요."
  - "기본 서류로"는 실제 고른 종류에 맞춰: 기본 서류 → "기본 서류로", 이력서 파일 → "이력서 파일로", 앱 맞춤본 → "앱 맞춤본으로", 모름 → "이력서 세션 맞춤본이 아닌 서류로". 단순하게 하려면 "이력서 세션 맞춤본이 아닌 서류로" 하나로 두어도 됨 — 개발자 판단, 짧고 자연스럽게.
- 이력서 세션 언급 삭제. 조건·닫기 동작은 그대로.

### 2) [지원 완료] 창 이력서 선택지

- **[지원 완료](새 기록) 창에서만**: 지난 이력서 파일("이력서 2026-11-02" 등)과 "모름"을 뺀다. 남는 것: 앱 맞춤본 리비전(있을 때), **이력서 세션 맞춤본(한 줄)**, 기본 서류 프로필 8개.
  - [기록 수정] 창은 지난 기록(메일로 가져온 452건 등)이 파일·모름을 쓰므로 지금 선택지를 유지한다. 단, 이력서 세션 맞춤본은 아래처럼 한 줄로 같이 바꾼다.
  - 지금 기록이 파일·모름인 상태에서 [지원 완료]를 다시 여는 경우(다시 지원 완료)는 새 기록이므로 똑같이 뺀다.
- **이력서 세션 맞춤본 한 줄**: 선택지 이름 "이력서 세션 맞춤본". 기록되는 프로필(D-33의 profileId)은 다음 순서로 정한다:
  1. 그 공고에서 [이력서 세션 요청 복사]를 할 때 고른 프로필 — 복사 표시(localStorage `cf:session-request-copied:{postingId}`)에 프로필 id도 함께 저장하도록 바꾼다(지금 값은 시각만. 옛 값이면 무시하고 다음 순서로).
  2. 없으면 분석 추천 1순위 프로필(지금 키트 기준).
  3. 없으면 직무 기본 프로필.
  - 창에는 선택지 아래(바탕 이력서 날짜 줄 근처)에 회색 작은 글자 "B4 오너십 기반"처럼 어떤 프로필로 기록되는지 한 줄 보인다. 다른 프로필로 바꾸는 별도 칸은 두지 않는다(요청: 하나로만).
  - 저장 값·라벨·통계는 D-33 그대로(kind 'session', profileId, baseDate). 지원 기록 표시도 그대로("이력서 세션 맞춤본 · B4 오너십 (날짜 이력서 기반)").
  - [기록 수정]에서 이미 session으로 기록된 것은 그 프로필을 유지한 한 줄로 보인다.
- 기본값(처음 골라지는 값)은 지금 규칙 그대로(파일·모름이 빠지면 그다음 순서로).

- 추가(사용자): 새 기록 창의 경력기술서·포트폴리오 칸에서도 "모름"을 뺀다(없음·파일은 유지, 수정 창은 유지).

### 3) 지난 기록 직접 입력 표 오류 글 잘림

- "지원일(YYYY-MM-DD) 필요"가 72px 칸에서 [X]에 가렸다. 오류 글을 "지원일 필요"로 줄이고 칸 안에서 어절 단위로 줄바꿈하게 한다(다른 칸 오류도 같은 칸·같은 방식).
