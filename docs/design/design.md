# 화면 디자인

- 상태: **디자인 B(코발트)로 결정** (2026-11-16)
- 근거: [../spec/screens.md](../spec/screens.md)(동작·문구), 아래 와이어프레임(배치)

## 1. 문서 구성

1. **와이어프레임** — [wireframes/index.html](wireframes/index.html)
   - 디자인 없이 화면마다 버튼 위치, 문구, 보여 줄 데이터, 상황별 모양을 정한다.
   - 9개 화면을 화면별·상황별 프레임으로 나눠 그렸다(빈 상태, 진행 중, 실패, 창 포함).
   - 통계 화면(`/stats`)은 [wireframes/stats.html](wireframes/stats.html)에 있다. 목업은 아직 없고, 구현할 때는 이 와이어프레임과 7장 색 표를 기준으로 한다.
   - 배치는 이것을 기준으로 한다.
2. **목업** — [mockups/index.html](mockups/index.html)
   - 와이어프레임 배치에 디자인 B를 입혀 실제 웹사이트처럼 만든 것이다. 구현할 때 시각 기준으로 쓴다.
   - 8개 화면을 모두 클릭해서 써 볼 수 있다: 대시보드, 공고 등록, 분석한 공고, 공고 상세, 기본 이력서, 가져오기, 사이트 반영, 설정.
   - 면접 준비 인쇄용 화면은 목업에 없고 와이어프레임만 있다.

## 3. 사이트 색

사이트는 **색 점 + 이름**으로 표시한다. 상태 배지는 채운 알약 모양이라, 색이 비슷해도 모양으로 구분된다. 사이트 색은 상태 색(코발트·청람·하늘·초록·주황)과 겹치지 않게 골랐다. 흰 바탕에서 글자 대비는 모두 4.5:1 이상이다.

| 사이트 | 색 |
|---|---|
| 리멤버 | `#0E7C86` (청록) |
| 원티드 | `#6741D9` (보라) |
| 그룹바이 | `#A15C00` (황토) |
| 잡코리아 | `#B5179E` (자홍) |
| 기타 | `#5B6475` (회색) |

사이트 색을 쓰는 곳:
- 대시보드 표, 요약 줄, 사이트별 묶음 이름표, 상태별 보드 카드
- 공고 상세 상단과 중복 경고 줄
- 지원 기록 탭
- 분석한 공고
- 가져오기의 사이트 선택
- 사이트 반영 카드 제목
- 설정의 사이트 로그인

## 4. 상태 색

| 상태 | 색 |
|---|---|
| 지원 | 회색 `#5B6475` |
| 서류합격 | 하늘 `#0369A1` |
| 과제·코딩테스트 | 청람 `#1F5FAD` (배지 배경 `#E8EEF7`) |
| 면접 (N차) | 코발트 `#2342C8` |
| 최종합격 | 초록 `#15803D` |
| 불합격 · 지원취소 | 흐린 회색 `#98A0AE` (배지 배경 없음) |

- 과제·코딩테스트(2026-11-20 추가)는 하늘과 코발트 사이의 파랑이다. 진행 순서(하늘 → 청람 → 코발트 → 초록)대로 색이 짙어지게 했다. 사이트 색(청록·보라·황토·자홍)과는 색상 계열이 다르다. 흰 바탕 대비 6.3:1, 배지 배경 위 5.4:1이다. 배지에는 늘 글자가 있으므로 하늘·코발트와 색만으로 구분하지 않아도 된다.

## 5. 대시보드 보기 4종

Notion 데이터베이스 보기 방식을 참고했다. 제목 아래 보기 탭으로 바꾼다. 와이어프레임은 1-2·1-3, 동작은 `screens.md` 1장 "보기 전환"에 있다.

- **전체**: 표. "제출한 이력서" 열을 포함한다.
- **사이트별**: 사이트 색 이름표로 묶고 접고 편다. 묶음 머리에 개수와 서류 통과율(`서류 통과 9 / 469 · 1.9%`, 통계 화면과 같은 정의, D-18).
- **상태별**: 6열 보드(지원 / 서류합격 / 과제·코딩테스트 / 면접 / 최종합격 / 종료). 카드를 끌어 상태를 바꾸면 상태 변경 창으로 확인한다.
- **이력서별**: 제출한 이력서의 기준 버전으로 묶는다. 어느 버전이 서류를 잘 통과했는지 본다.

## 6. 결정 반영

- 공고 상세 상단에 [공고 삭제]를 둔다. 지원 전에만 보인다(D-02).
- [회사 연결 변경] 창에서 연결 바꾸기, 별칭 추가, 다른 회사와 합치기를 한다(D-04).
- 지원 완료 창과 공고 등록에 기타 사이트의 출처 이름 칸을 둔다(D-03).
- 지원 기록 탭과 대시보드의 펼친 행에 [기록 수정]·[기록 삭제]를 둔다(D-01).
- 다크 모드는 없다(D-06).
- 설정 화면의 기본 모델(D-05)도 목업에 반영했다.

결정 기록 전체는 [../decisions.md](../decisions.md)에 있다.

## 7. 통계 그래프 색 (D-18·D-20)

통계 화면(`screens.md` 10장)의 그래프는 직접 그린 SVG다. 새 색은 "무응답" 하나만 더하고, 나머지는 상태 색과 사이트 색을 그대로 쓴다.

| 계열 | 색 | 근거 |
|---|---|---|
| 서류 통과 | 하늘 `#0369A1` | 상태 색 "서류합격" |
| 과제·코딩테스트 (단계별 흐름) | 청람 `#1F5FAD` | 상태 색 "과제·코딩테스트" |
| 면접 (단계별 흐름) | 코발트 `#2342C8` | 상태 색 "면접" |
| 최종합격 (단계별 흐름) | 초록 `#15803D` | 상태 색 "최종합격" |
| 지원 (단계별 흐름 첫 줄) | 회색 `#5B6475` | 상태 색 "지원" |
| 불합격 | 흐린 회색 `#98A0AE` | 상태 색 "불합격" |
| 무응답 | 연회색 `#D5D9E1` (새 토큰) | 불합격보다 옅게. 면적이 커도 눈에 덜 띄게 |
| 대기 | 흰 면 + `#5B6475` 1px 점선 테두리 | 아직 결과가 아님을 모양으로 |
| 막대 위 통과율 숫자 | 코발트 `#2342C8`, 표본 적음이면 보조 글자 `#5B6475` | 강조 색 |
| 사이트별 막대 | 사이트 색(3장) | 다른 화면과 같은 사이트 = 같은 색 |
| 서류 버전·요일 막대 | 통과 부분 하늘 `#0369A1`, 나머지 연회색 `#D5D9E1` | 범주 자체에 의미 있는 색이 없음 |

- 색만으로 구분하지 않는다. 범례와 표가 늘 함께 있고, 대기는 점선 테두리로 모양이 다르다.
- 막대마다 SVG `<title>`을 달아 마우스를 올리면 숫자가 보이게 한다. 애니메이션은 없다.
- 숫자는 고정폭 숫자로 쓴다.
