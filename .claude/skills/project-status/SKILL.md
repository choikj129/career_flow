# 프로젝트 현황 보고

PM 역할(`.claude/rules/pm.md`)로 현황을 확인하고 보고한다. 추측하지 않고 확인한 것만 쓴다.

## 1. 사실 모으기

- `docs/pm/status.md`: 마일스톤, 일정, 백로그, 위험, 사용자 할 일
- `docs/decisions.md`의 "정할 것": 열린 결정
- `git status -sb`, `git log --oneline -15`, 브랜치 목록, `origin/main`과의 차이(push 안 된 커밋 수)
- 진행 중인 에이전트 작업
- 진행 중인 기능 작업 기록 `docs/work/*.md`(`_template.md` 제외)의 상태와 회차
- 필요하면 `npm test`로 지금 `main`이 통과하는지 본다(요청이 "빠르게"면 생략하고 생략했다고 적는다).

## 2. status.md 갱신

- 사실과 다른 칸을 고친다: 상태, 지금 단계, 마지막 갱신일, 사용자 할 일 완료 여부.
- 목표일이 지났는데 끝나지 않은 마일스톤은 "지연"으로 표시한다. 이유와 새 예상을 비고에 적는다. 목표일 자체를 바꾸는 것은 사용자 결정이다.
- 변경 이력에 한 줄을 추가한다.
- 바뀐 것이 있으면 `.claude/rules/git.md`대로 커밋·병합한다(push는 묻는다).

## 3. 보고 (사용자에게, 짧게)

1. **지금 위치**: 마일스톤과 상태 한 줄
2. **일정**: 목표일 대비(예정대로 / 지연 n일과 이유)
3. **최근 끝난 것**: 지난 보고 이후
4. **다음 할 일**: 우선순위 3개 이내
5. **사용자가 할 일 / 정할 것**: 있으면
6. **위험**: 새로 생겼거나 커진 것만
