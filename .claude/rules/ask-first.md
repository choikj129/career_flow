# 결정이 필요하면 멈추고 묻기

작업 중 아래 같은 일이 생기면 스스로 정해서 진행하지 않는다. 그 자리에서 멈추고 사용자에게 묻는다.

## 멈추고 물을 일

- **큰 결정**
  - 데이터 모델·DB 스키마를 바꾸는 일 (기획서에 없는 테이블, 컬럼, 관계)
  - 사용 흐름이 바뀌는 일
  - 기획서·결정 기록과 다르게 가야 하는 일
  - 새 외부 서비스, 새 비용, 새 권한이 필요한 일
- **꼭 사용자가 정해야 할 일**
  - 개인정보·보관 정책
  - 사용자 PC나 외부 사이트에 영향을 주는 동작
  - 실제 `claude` 호출을 계획보다 많이 하는 일
  - 계획에 없는 기능을 넣거나 빼는 일
- 선택지가 여럿이고, 어느 쪽을 고르느냐에 따라 만드는 것이 달라지는 일

## 묻는 방법

- `docs/decisions.md`에 `D-번호` 항목을 **짧게** 만든다. 배경 1~2줄, 선택지는 한 줄씩(추천 표시). 코드·파일 경로·줄 번호·함수 이름은 넣지 않고 사용자가 바로 이해할 말로 쓴다. 근거와 자세한 내용은 작업 기록(`docs/work/`)에 둔다.
- 사용자에게 짧게 알린다.
- 그 결정에 걸린 작업은 멈춘다.
- 결정과 상관없는 작업은 계속해도 된다.

## 서브에이전트

서브에이전트는 위 상황을 만나면 그 부분을 하지 않고 작업을 끝낸다. 무엇을 왜 정해야 하는지는 보고서의 "정할 것"에 적는다. 그러면 호출한 쪽이 사용자에게 묻는다.

## 묻지 않아도 되는 것

계획에 이미 정해진 것, 되돌리기 쉬운 작은 구현 선택(이름, 내부 구조, 문구 다듬기)은 정하고 보고서에 적는다.
